

# Simply framework
[Simply Framework](https://amorfx.github.io/simply-documentation/) es un **framework de WordPress** que te ofrece el componente de inyección de dependencias de Symfony y el motor de plantillas PHP Twig.

Simply no es un framework en el que te vayas a perder si ya llevas tiempo desarrollando en WordPress.

Te permitirá ahorrar tiempo de desarrollo al ofrecerte inyección de dependencias, así como la automatización de tareas recurrentes en WordPress.

## Instalación
Toda la documentación y el proceso de instalación están [disponibles aquí](https://amorfx.github.io/simply-documentation/getting-started/installation). Léelo atentamente.

## Filosofía

El framework sigue varios puntos importantes con el fin de no complicar el desarrollo:
- no modificar la estructura general de WordPress
- evitar añadir una gran capa adicional que haría más complejo el desarrollo de plugins o temas
- simplificar elementos añadidos a WordPress mediante procesos automatizados (tipos de entrada, taxonomías...)
- utilizar programación orientada a objetos

Por ello, el framework fue desarrollado como un plugin de uso obligatorio para WordPress.
